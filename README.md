# 제주 전력수요 예보기 (PT#2)

기온·습도 예보를 넣으면 제주의 시간별 전력수요, 피크 시각, 피크 등급을 예측하는 웹앱입니다.
2025년 제주 시간별 전력수요와 ASOS 4개 관측소(제주·고산·서귀포·성산) 평균 기온·습도로 학습했습니다.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `jeju_2025_merged.csv` | 학습 데이터 (2025년 8,760시간) |
| `model.py` | 공통 함수: 입력변수 만들기, 예측, 수요 분해 |
| `train.py` | 모형 학습 후 `model.pkl` 저장 |
| `model.pkl` | 학습된 모형 (train.py 실행 결과) |
| `app.py` | Streamlit 화면 |

## 실행 방법 (내 PC)
```bash
pip install -r requirements.txt
python train.py        # model.pkl 만들기 (이미 있으면 생략 가능)
streamlit run app.py   # 브라우저가 자동으로 열림 (http://localhost:8501)
```

## 화면 구성
1. **예측**: 날짜·휴일·기상 예보 입력 → 24시간 예측 곡선, 피크 수요·시각·등급, 수요 분해(기본/냉방/난방/습도)
2. **시나리오**: 기온·습도를 바꿨을 때 피크 변화 (폭염·한파 대비)
3. **모형 설명**: U자 산점도, 기준온도, 검증 성능

## 기상 예보 입력 방법
- **간단 입력**: 최저·최고기온, 평균습도만 넣으면 2025년 같은 달의 하루 패턴으로 24시간 값을 만들어 줍니다. 표에서 시간별 값을 직접 고칠 수도 있습니다.
- **CSV 업로드**: 화면에서 양식을 내려받아 `시, 기온, 습도` 24행을 채워 올립니다.

## 피크 등급 기준
- 🟠 주의: 2025년 시간별 수요 상위 10% (약 934 MW 이상)
- 🔴 경고: 2025년 시간별 수요 상위 3% (약 1,020 MW 이상)
